## Animation generation

SALF1's additional motion layer is original runtime procedural animation code. It does not copy Fab's 46 paid animation files.

The procedural layer drives secondary feline behavior such as:
- breathing
- head scanning / look-around
- ear response
- tail balance/sway
- blink timing
- jaw micro-motion
- alternating quadruped gait
- lower stalking posture

For future imported clips, the runtime also recognizes common clip names for idle, walk, run, turns, sitting, standing and rest.
