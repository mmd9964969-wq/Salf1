# Free Panther motion sources

## 1. Sketchfab — Black Panther
https://sketchfab.com/3d-models/black-panther-7fca11c89cca4362a525c891a8345112

- Downloadable animal panther model
- CC BY 4.0
- The listing references a simple big-cat animation
- Attribution is required

This is the preferred free animal-panther model candidate for a future shipped panther.glb.

## 2. Mesh2Motion
https://github.com/Mesh2Motion/mesh2motion-assets

- Art assets are CC0
- Provides animal rigs/animations and an open tool for importing a GLB, fitting an animal rig and exporting animated GLB
- Used as the legal/procedural motion pipeline reference

## 3. SALF1 procedural behavior layer

Already integrated in src/components/nexa/onboarding.tsx.

The runtime adds original, non-Fab motion for:
- breathing
- head scanning
- ear response
- tail balance
- gait oscillation
- stalking posture
- blink timing
- jaw micro-motion

No paid Fab animation file is copied, extracted or redistributed.
