## Design direction extracted from the references

- Black Javan leopard silhouette and proportions
- Realistic feline anatomy rather than cartoon geometry
- Dark/black coat with subtle specular highlights
- Realistic head, muzzle, ears, eyes and whisker-area detail
- Natural quadruped stance and body weight
- Cinematic side/three-quarter presentation
- Black + ice/silver visual language for SALF1
- Silver crown remains a SALF1-specific overlay, not part of the Fab asset

## Important

The Fab listing states that its commercial package contains 46 animations, rigging, groom and 4K textures. Those paid package files are NOT included in this repository. SALF1 must use a separately licensed/free model and separately licensed animations for the actual runtime character.

This reference file exists so future visual/3D implementation work consistently targets the approved Fab reference appearance.
