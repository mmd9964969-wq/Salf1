# SALF1 Panther Asset

Production asset target: realistic melanistic leopard / black panther.

Selected candidate for evaluation:
- Black Javan Leopard — Fab
- GLB / glTF available
- Rigged: Yes
- Animated: Yes
- 46 animations
- 4K textures
- Groom asset: Yes
- Physics asset: Yes
- Approx. 16,812 vertices / 31,922 triangles

Source:
https://www.fab.com/listings/003ba7b1-e6f6-4bc9-9f9f-740fa1e54689

Integration target:
public/assets/panther/panther.glb

Required production checks before publishing:
1. Confirm commercial/website license.
2. Download the licensed GLB package.
3. Place the final file at panther.glb.
4. Verify animation names and select idle/walk/roam clips.
5. Verify fur/groom compatibility with Three.js/WebGL.
6. Optimize a mobile variant if the desktop asset is too heavy.

The application intentionally does not substitute a primitive/cartoon panther when the production asset is absent.
